## What does this PR do?

WIP first version: adds a one-column left rail to the live TUI composer without adding rows. The rail is shared by multiline draft rows and the active `TextInput`; input layout and mouse drag coordinates are adjusted for the consumed column.

## Related Issue

Fixes #127332

## Type of Change

- [x] ✨ New feature (non-breaking change that adds functionality)

## Changes Made

- Render a one-column border rail for every composer draft row in `ui-tui/src/components/appLayout.tsx`.
- Reduce the measured input width by one column so wrapping matches the rendered composer width.
- Keep mouse selection anchored to the input after the rail is added.

## How to Test

1. Run the TUI in native and alternate-screen modes.
2. Check the composer at 40, 80, and 120 columns.
3. Type and paste multiline text, then verify the rail remains aligned and mouse selection still targets the input.
