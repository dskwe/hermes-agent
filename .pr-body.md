## What does this PR do?

WIP first version: make Browser Use screenshot discovery preserve absolute paths containing spaces, so fresh screenshots can be attached to native-vision results instead of being missed.

## Related Issue

Fixes #127097

## Type of Change

- [x] 🐛 Bug fix (non-breaking change that fixes an issue)
- [x] ✅ Tests (adding or improving test coverage)

## Changes Made

- Update `_find_screenshot` path matching in `tools/browser_use_cli.py` to accept spaces in POSIX and Windows absolute paths.
- Add regression coverage for a screenshot under a path containing spaces.

## How to Test

1. Run `pytest tests/tools/test_browser_use_cli.py -q`.
2. Verify a fresh screenshot path containing spaces is returned by `_find_screenshot`.
